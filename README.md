# 前沿课程

发现全球大学的前沿课程与开源学习项目，让每一次好奇都有下一步。

中文课程发现网站，采用封面卡片、来源标注与详情弹窗。关注世界模型、智能体、大语言模型、智能编程、生成式搜索优化和具身智能。

[打开前沿课程](https://giao-123-sun.github.io/frontier-courses/)

公开托管版提供浏览、搜索、筛选、收藏与本机兴趣匹配，每日自动检查来源。邮箱与模型推荐需要部署同源后台并配置相应服务；公开静态版不收集邮箱。

## 已实现

- 搜索课程、原始名称、大学和项目；按主题、类型、地区筛选。
- 查看内容概述、学习目标、先修要求、来源与开放程度，跳转原始资源。
- 本机收藏与兴趣档案；基于主题和基础的匹配推荐。
- 可接入兼容聊天补全协议的模型，按角色和学习目标给出中文推荐理由。服务未配置时明确说明，不冒充模型结果。
- 每日检查已配置大学来源和开源项目；自动发现的候选进入待核验列表。网络失败保留原目录，不把抓取时间当作课程发布时间。
- 邮箱双重确认、每周按主题发送摘要、发送记录去重、退订删除、请求限速。未配置发件服务时不收集邮箱。
- 响应式布局、键盘操作、弹窗焦点管理、减少动态效果支持。

## 本地运行

需要 Node.js 22.12 或以上版本。

```sh
npm ci
npm run build
npm start
```

访问 `http://127.0.0.1:3001`。开发时另开终端运行 `npm run dev`，前端开发地址为 `http://127.0.0.1:5173`。

首次收录包含 9 个经人工核验的真实资源。宾夕法尼亚大学世界模型课程以公开课程目录为来源；斯坦福循环工程属于现代软件开发者课程的内容，不标为独立课程。收录不代表完整录像免费开放或允许公众正式入学。

## 服务配置

复制 `.env.example` 为 `.env`，仅在服务器本地填写值。不要提交密码、邮件地址清单或模型密钥。

邮件需要 `SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASS`、`SMTP_FROM` 和网站的 `PUBLIC_URL`。使用事务邮件服务及经验证的发件域名；连接要求加密。配置完成后重启服务，订阅入口才会开放。

智能推荐需要 `AI_BASE_URL`、`AI_API_KEY` 和 `AI_MODEL`。基础地址填写兼容聊天补全接口的地址前缀，例如服务提供商给出的 `/v1` 地址。密钥始终留在服务端。个人档案默认只在浏览器保存，用户主动请求智能推荐才发送角色、目标、主题和基础；邮箱从不提交给模型。

每个地址每小时最多请求 5 次确认邮件，每小时最多请求 12 次智能推荐。已有订阅邮箱不会被匿名请求改写兴趣；要更换订阅主题，可退订后重新订阅。

## 自动更新

```sh
npm run collect
```

服务运行期间，北京时间每天 03:17 检查来源，每周一 09:00 发送确认订阅者关注主题的简报。没有未发送内容就不发邮件。每天 02:10 清除 48 小时未确认的邮箱记录。定时器随服务运行，停机时错过的计划不会自动补跑。

`data/sources.json` 配置中美大学来源。`public/catalog.json` 保存公开资源、最近检查结果和候选。采集遵循来源的访问规则，限制请求时间、体积与频率；遇到验证页面或规则不明时跳过，页面展示失败原因。开源项目通过官方接口检测最新提交，不能把提交更新等同于新课程发布。

**范围说明：** 当前是已配置来源监测，不是全网搜索引擎。候选链接不会未经核验自动变成已推荐课程。新增资源应确认作者、所属学校、访问方式和原始链接后写入目录。封面是本项目原创主题插图，并非官方课程封面。

## 部署

前端与后台采用同源部署，无需跨站发送个人信息。生产环境在本机地址运行后台，由反向代理提供安全连接。部署示例见 [deploy/README.md](deploy/README.md)。订阅数据保存在独立私有数据库目录，不放在网页可访问的目录或公开仓库。

项目使用界面组件库、构建工具、服务框架、数据库、邮件和抓取等成熟依赖；不引入额外的平台配置层。前端、采集、订阅和推荐分别维护。

## 验证

```sh
npm test
npm run build
# 先运行 npm start，再运行以下浏览器检查；本机默认使用已安装的 Chrome。

```

测试覆盖组合筛选、来源安全、确认前不发简报、确认过期、发送失败、重复发送、旧邮件退订与数据删除。浏览器检查覆盖桌面与手机视口、搜索、详情、收藏持久化和兴趣设置。
